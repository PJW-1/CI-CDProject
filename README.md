# 🖐️ 실시간 손동작 인식 원격 그림판 (Air Canvas System)

> **실시간 영상 스트리밍과 컴퓨터 비전을 활용한 3대 마이크로서비스 웹 아키텍처**

---

## 🏛️ 시스템 아키텍처 (3개의 독립된 컨테이너)

```
[ 📱 스마트폰 카메라 ]
      │ (1. QR 스캔 ➔ 세션 매칭 & HTTPS 실시간 스트리밍)
      ▼
[ 1️⃣ Container A: 웹 / 보안 서버 (Port 8443) ]
      │ - 자체 로컬 SSL 인증서 자동 발급 (카메라 권한 획득)
      │ - 1:1 QR 세션 동기화 및 최종 웹 캔버스(그림판) 렌더링
      ▼ (무거운 픽셀 영상 전달)
[ 2️⃣ Container B: 영상 분석 엔진 (MediaPipe Vision) ]
      │ - 손 영역 포착 ➔ 21개 관절 랜드마크(x, y) 추출
      │ - 무거운 픽셀 데이터를 초경량 좌표 배열로 압축
      ▼ (21개 [x, y] 좌표 전달)
[ 3️⃣ Container C: 동작 판별 엔진 (Gesture Logic) ]
      │ - 21개 좌표 간의 프레임별 변화량(Delta) 계산
      │   👉 검지만 폄: [그리기 펜 모드]
      │   👉 검지+중지 폄: [지우개 모드]
      │   👉 엄지-검지 벌림: [화면 확대 Zoom In]
      │   👉 엄지-검지 오므림: [화면 축소 Zoom Out]
      ▼ (초경량 제어 명령: DRAW, x=150, y=200)
[ 🖥️ PC 웹 브라우저 HTML5 Canvas 실시간 드로잉! ]
```

---

## 🚀 빠른 시작 (How to Run)

### 1. 도커로 실행 (원클릭)

프로젝트 폴더(`C:\Users\pjw\Desktop\air-canvas-system`)에서 아래 명령어를 실행합니다:

```bash
docker compose up --build
```

## 🎮 테스트 방법 (30초 가이드)

1. **PC 브라우저 접속:**  
   * 크롬 브라우저에서 `https://localhost:8443` 접속
   * *(※ 자체 인증서 경고가 뜨면 **[고급] ➔ [localhost(안전하지 않음)으로 이동]** 클릭)*
2. **화면에 나타난 QR 코드 스캔:**  
   * 스마트폰 기본 카메라 앱으로 PC 화면의 QR 코드를 스캔합니다.
3. **모바일 카메라 권한 허용:**  
   * 폰 브라우저에서 **[고급] ➔ [계속 진행]** 클릭 후 카메라 권한을 허용합니다.
4. **원격 드로잉 시작:**  
   * 스마트폰 카메라에 손을 비추고 검지를 펴서 허공에 그림을 그리면 PC 캔버스에 실시간으로 그려집니다!

## 🖐️ 4대 손동작 규칙

| 동작 | 손 모양 | 기능 |
| :--- | :--- | :--- |
| **펜 모드 (Draw)** | 검지만 폄 | 캔버스에 선 그리기 |
| **지우개 모드 (Erase)** | 검지 + 중지 폄 | 지나간 영역 지우기 |
| **확대 (Zoom In)** | 엄지-검지 거리 벌리기 | 화면 확대 |
| **축소 (Zoom Out)** | 엄지-검지 거리 오므리기 | 화면 축소 |
| **대기 (Hover)** | 손바닥 전체 펴기 / 주먹 | 커서 위치만 이동 |
